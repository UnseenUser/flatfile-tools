Sheetgrab privacy policy

Last updated: 19 November 2026

Sheetgrab is a Chrome extension that copies a table from a web page into a new Google Sheet in your own Google account.

What it collects

Nothing.

There is no Sheetgrab server, no account, no sign-up, no analytics, no crash reporting and no telemetry. Nothing is sent anywhere except as described in the next section, and nothing is stored anywhere except in your own Google account.

What leaves your computer, and where it goes

One thing, in one situation.

When you click the extension icon, pick a table and press Send to Sheets, the contents of that table are sent directly from your browser to sheets.googleapis.com, which is Google's own Sheets API, using an access token your browser obtained from Google. The new spreadsheet is created in your Google Drive, under your account.

That request goes from your browser to Google. It does not pass through any server belonging to Sheetgrab or its developer, because no such server exists.

https://sheets.googleapis.com/* is the only host the extension is permitted to contact. You can confirm this yourself: open the extension's folder and read host_permissions in manifest.json. Chrome will not let it reach any other address.

What is stored

Nothing, on either side.

The table is held in your browser's memory for the length of one request and is discarded. The extension writes nothing to browser storage. It does not request the storage permission at all, so it could not store anything even if its code tried to.

Google account access

Sheetgrab requests one Google scope:

https://www.googleapis.com/auth/drive.file

This scope grants access only to files the extension itself creates. It cannot read, change, list or delete anything that was already in your Google Drive. Documents, photos, spreadsheets you made yourself, files other people shared with you: all of it is outside what this scope can reach.

The wider drive and spreadsheets scopes would have been easier to build with. They were not used, deliberately.

Sheetgrab never sees your Google password. Signing in happens in Google's own window, through Chrome's identity service, and the extension receives only a short-lived access token which it uses for the one request and does not store.

Sheetgrab's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Specifically, data obtained through those APIs is not transferred to anyone, is not used for advertising, is not used to train any model, and is not read by any human. It is used for the single purpose of creating the spreadsheet you asked for.

Permissions, and why each one exists

PermissionWhat it is for
------
activeTabRead the page you are looking at, at the moment you click the icon, and no other page, and not before you click.
scriptingPlace the table picker onto that page when you click.
identityAsk Google for the token that lets the sheet be created in your account.
host: sheets.googleapis.comSend the table to Google's Sheets API. The only host that can be contacted.

Children

Sheetgrab is a tool for working with data on web pages and is not directed at children.

Changes
